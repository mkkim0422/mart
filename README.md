# 마트노트 (MartNote)

마트별로 장보기 리스트를 만들고, 홈화면 위젯에서 한눈에 확인한 뒤 앱에서 1초 만에 체크하는 한국형 초심플 안드로이드 앱.

- **Package**: `com.rldjrgo.grocerynote`
- **Min SDK**: 26 (Android 8.0)
- **Target SDK**: 36 (Android 16)
- **Stack**: Kotlin · Jetpack Compose · Glance · Room · Hilt · Coroutines/Flow

자세한 설계, 디자인 시스템, 위젯 명세는 [`CLAUDE.md`](./CLAUDE.md) 참고.
