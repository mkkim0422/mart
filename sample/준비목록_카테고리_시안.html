정한 것

  • 순서: 검색 → 카테고리 칩 한 줄(가로 스크롤, 마트 탭과 같은 둥근 모양) → 목록. 격자 버튼은 화면 절반을 먹어서 안 씀.
  • '전체': 최근 본 것 · 자주 찾는 것 다음에 카테고리마다 4개만 + "더 보기". 누르면 그 칩으로 넘어감. 300개를 한 번에 늘어놓지 않음.
  • '요리' 칩: 지금 앱 그대로 — 찌개·국·탕 / 메인 요리 / 반찬 … 소제목으로 나뉨.
  • 검색: 칩과 상관없이 전체에서 찾음. 결과 카드 아래에 작게 어느 칸인지(아이 등) 표시.
  • 상세 칸 이름: 요리 = 재료 / 넣어도 좋은 것 / 양념 "집에 없는 것만" / 준비물 · 요리 아닌 것 = 꼭 필요한 것 / 있으면 좋은 것 / 집에 있는지 확인. 데이터 형식(한 줄 7칸)은 그대로, 보여 주는 이름만 바뀜.
  • 기존 규칙 유지: 미리 체크 안 함, 이미 마트 목록에 있으면 흐리게 "○○에 있음", 양 없음. 요리 아닌 목록엔 "만드는 법 보기" 없음.
  • 목록 내용은 '살 것'만: 여권·충전기 같은 챙길 것은 빼고, 살 것 위주(예: "여행 가기 전 살 것").

정해 주셔야 할 것

  • 탭 이름: 시안은 "준비 목록". 다른 후보 — "뭐 사지?", "재료·준비물". 화면 제목 = 탭 이름 규칙은 유지.
  • 카테고리 6개(전체 포함 7칩): 🍲요리 · 🎉명절·행사 · ⛺나들이·여행 · 👶아이 · 🏠생활. 반려동물은 처음엔 '생활'에 넣음.
  • 시안의 아이·생활 목록 이름은 예시입니다. 실제 내용(항목)은 따로 초안 만들어 검토받을게요.
