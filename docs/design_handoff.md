## 1. 앱 정체성

| 항목 | 값 |
|---|---|
| 앱 이름 (KO) | **마트노트** |
| 앱 이름 (EN) | MartNote |
| 패키지명 (영구) | `com.rldjrgo.grocerynote` (변경 불가) |
| 한 줄 정의 | 마트별 장보기 리스트를 만들고, 홈화면 위젯에서 한눈에 확인한 뒤 앱에서 1초 만에 체크하는 한국형 초심플 앱 |
| 플랫폼 | Android 전용 (Android 8.0 / API 26 이상) |
| 버전 | 1.0.0 (출시 준비 중) |

### 1.1 사업 모델

- **하단 배너 광고 1개만** (전면/네이티브/리워드/팝업 광고 일절 없음)
- **인앱결제 1종**: "광고 제거" ₩1,900 (1회 결제 영구 제거, 앱 자체는 평생 무료)
- 회원가입·로그인 없음. 전 데이터 로컬 저장(서버 전송 없음)

### 1.2 타겟 사용자

- **1차**: 30~50대 한국 여성 (주부·워킹맘)
- **2차**: 20~40대 1인 가구
- 시각 톤은 1차 타겟 기준으로: 친근하지만 신뢰감 있고, 복잡하지 않게.

### 1.3 3대 차별점 (북극성 — 디자인도 이걸 시각화해야 함)

1. **마트별 분리 리스트** — 쿠팡/다이소처럼 가게마다 따로. 가로 스크롤 탭. **#1 핵심 USP.**
2. **홈화면 위젯** — 마트별 리스트를 5가지 크기 위젯으로 한눈에. 자유 리사이즈.
3. **이름만, 1초 입력/체크** — 가격·수량·메모 없음. 마찰 제로.

> 위젯은 **표시 + 딥링크 전용**(위젯에서 직접 체크 안 함). 위젯 탭 → 앱이 해당 마트로 열림 → 앱에서 체크. 스크린샷/일러스트에서 "위젯에서 체크 누르는 장면"은 그리지 말 것.

### 1.4 Hard No 정책 (시각물에 절대 등장 금지)

가격 입력 / 수량·단위 입력 / 메모 / 카톡 Import / 회원가입·로그인 화면 / 카테고리·태그 / 통계·그래프 탭 / 하단 탭 4개 이상.
→ 스크린샷·일러스트에 **숫자 가격표, 수량 스테퍼, 통계 차트, 로그인 폼을 그리면 안 됨.** 항목은 "이름"만.

## 7. 출력 형식 가이드

### 7.1 앱 아이콘

- **Play Store 아이콘**: 512×512 PNG, 32-bit, **알파 없음(불투명)**, 정사각. 세이프존 고려(스토어가 마스킹).
- **앱 내 어댑티브 아이콘**: 108×108dp 캔버스, **foreground / background 2레이어 분리** 제공.
  - 안전 영역(safe zone): 중앙 **66dp 원** 안에 핵심 그래픽 배치(바깥 ~18dp는 런처 마스크/패럴럭스로 잘릴 수 있음).
  - background는 단색 또는 아주 약한 톤(웜 오프화이트/연블루). foreground는 카트+도트.
  - **monochrome 레이어 1종 추가 제공**(단색 실루엣, Android 13+ 테마 아이콘용 — 배경 투명, 단색 형태만).
- 픽셀 export 필요 시 mdpi~xxxhdpi 대응(48/72/96/144/192 px) 또는 벡터(SVG/PDF) 원본 전달.

### 7.2 Play Store 스크린샷

- 해상도: **1080×1920**(9:16) 또는 **1080×2400**(20:9, 최신 안드로이드 비율) — 둘 중 하나로 통일, 최소 2장 권장 4~8장.
- 폰 목업 프레임 사용 가능. 화면 내용은 §3 와이어프레임 기준(쿠팡/다이소 기본).
- 카피 오버레이는 §5 핵심 메시지 3종 활용. 가격/수량/통계 UI 절대 노출 금지(§1.4).
- **라이트/다크 모드 각각** 한 세트씩 제작 권장(다크 토큰 §2.2).

### 7.3 온보딩 일러스트 (3종)

- 권장 비율: 정사각~세로(예: 1:1 또는 4:5), 화면 중앙 96dp 아이콘 자리에 들어가는 **심플 일러스트/아이콘** 스타일.
- 모티프: ① 마트별 분리 ② 홈화면 위젯 ③ 이름만 1초 입력(§3.1).
- 스타일: 플랫, 브랜드 블루 + 마트색 포인트, 라인 단순.
- **다크모드 대응 필수** — 라이트/다크 양쪽에서 모두 또렷하게(투명 배경 권장, 색은 양 모드에서 대비 확보).
