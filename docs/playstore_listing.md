## 3. 앱 콘텐츠 (필수 선언)

### 광고 포함 여부
- **예, 광고가 포함되어 있습니다** (Google AdMob 배너)

### 데이터 보안 (Data safety) — AdMob 배너 기준
**"앱이 사용자 데이터를 수집/공유하나요?" → 예** (광고 SDK 때문)

수집/공유 항목:
| 데이터 유형 | 수집 | 공유 | 목적 | 비고 |
|---|---|---|---|---|
| 기기 또는 기타 ID (광고 ID) | 예 | 예 | 광고 또는 마케팅 | AdMob |
| 앱 활동 – 앱 상호작용 | 예 | 예 | 광고, 분석 | AdMob |
| 대략적 위치 | (AdMob 설정에 따라) | 〃 | 광고 | 보수적으로 "예" 선택 가능 |

추가 질문 답변:
- 전송 중 데이터 암호화: **예**
- 사용자가 데이터 삭제를 요청할 수 있나요: 장보기 데이터는 **기기에만 저장**(서버 전송 없음) → 앱 삭제 시 모두 삭제됨
- ⚠️ 장보기 항목/마트 이름은 **기기 로컬(Room DB)에만** 저장되고 외부로 전송되지 않으므로 Play 기준 "수집"에 해당하지 않음. 위 표는 **AdMob 광고 SDK가 수집하는 것**만 신고하면 됩니다.
- 정확한 신고는 AdMob 공식 데이터 보안 가이드 참고:
  https://support.google.com/admob/answer/11150250

### 1.5.0 데이터 보안 확인 — 공유 링크 단축
- 사용자가 **공유 버튼을 누를 때만** 그 마트 이름·항목 이름이 링크 단축 서비스(is.gd, 실패 시 tinyurl)로 전송됨 → 짧은 링크를 받아 메시지에 넣음. 계정·기기 ID·위치는 보내지 않음.
- Play 기준: 사용자가 직접 시작한 공유이고 사용자가 예상하는 전송이라 "공유(Sharing)" 신고 예외에 해당. 다만 데이터 보안 양식의 **"수집" 항목에 "앱 활동 → 기타 사용자 생성 콘텐츠(장보기 항목 이름), 앱 기능 목적, 선택 사항"**을 추가해 두면 안전함.
- 개인정보처리방침에도 한 줄 추가 권장: "목록 공유 시 링크를 짧게 만들기 위해 마트·항목 이름이 링크 단축 서비스(is.gd/tinyurl)로 전송됩니다."
